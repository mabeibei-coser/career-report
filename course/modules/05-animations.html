让一切动起来

动画、图表、PDF 导出与设计模式 — 舞台灯光师的艺术

动画和视觉效果就像舞台灯光：戏（功能）没有灯光也能演，但好的灯光能把体验从"还行"变成"哇塞"。代码是剧本，动画就是灯光设计。

动画的秘密 — Framer Motion

打开这个应用的首页，你会看到文字优雅地浮现、数字自动跳动、卡片错落有致地出现。这些不是魔法——它们是用代码精心编排的"灯光效果"。

⬆️

fadeUp

从下往上浮现（文字、标题常用）

🔍

scaleReveal

从小变大出现（卡片、图表常用）

🔢

AnimatedCounter

数字从 0 跳到目标值（统计数据常用）

🎭

stagger

子元素依次出场（列表项常用）

const fadeUp = {
  hidden: { opacity: 0, y: 20 },
  visible: {
    opacity: 1,
    y: 0,
    transition: {
      duration: 0.6,
      ease: [0.22, 1, 0.36, 1]
    }
  }
};
第 1 行 定义一个动画效果叫 fadeUp...
第 2 行 隐藏状态：完全透明（opacity 为 0），位置往下偏 20 像素
第 3-5 行 可见状态：完全显示（opacity 为 1），回到原来的位置（y 为 0）
第 6-7 行 过渡设置：花 0.6 秒完成
第 8 行 使用自定义缓动曲线 — 开始快、结束慢，看起来更自然

加载页的精妙设计 — 并行操作

加载页是整个应用最巧妙的设计之一：它同时运行动画和 API 调用，用视觉效果掩盖等待时间。

1

开始

同时启动两个任务 — 就像左手画圆、右手画方，两件事同时进行。

2

任务 A（前台）

播放 8 步动画，总共约 38 秒。用户看到的是精心设计的进度展示。

3

任务 B（后台）

调用 AI 生成报告，时间不确定。用户看不到这个过程。

4

等待

两个任务都完成后才跳转到报告页 — 缺一不可。

5

保险机制

如果动画放完了 API 还没好，显示"正在等待..." — 不让用户干等着不知道发生了什么。

并行操作是软件工程中非常重要的概念。就像厨师可以在等水烧开的时候切菜一样，程序也可以同时做多件事。这里用动画掩盖了等待时间，让用户感觉一切都在有序进行。

数据可视化 — Recharts 图表

报告页里有两种图表，它们让枯燥的数据变成直观的视觉呈现。这两种图表都来自 Recharts 库。

🕸️

RadarChart（雷达图）

展示 5 个能力维度的得分，像蜘蛛网一样。每个角代表一个维度，线条围出的面积越大，综合能力越强。

🥧

PieChart（饼图）

展示职责分布的权重，每块大小代表占比。一眼就能看出哪部分最重要。

<ResponsiveContainer width="100%" height={300}>
  <RadarChart data={dimensions}>
    <PolarGrid />
    <PolarAngleAxis dataKey="name" />
    <Radar dataKey="score"
      fill="#3b82f6"
      fillOpacity={0.3} />
  </RadarChart>
</ResponsiveContainer>
第 1 行 创建一个自适应大小的容器，高 300 像素
第 2 行 在容器里放一个雷达图，数据来自 dimensions 数组
第 3 行 画网格线（蜘蛛网的骨架）
第 4 行 在每个角标上维度名称（如"沟通能力"、"技术能力"）
第 5-7 行 画数据区域，蓝色填充，30% 透明度

PDF 导出 — 把网页变成文件

报告生成后，用户可以导出 PDF 文件。这个过程用到两个工具：html2canvas 负责"拍照"，jsPDF 负责"装进相册"。

1
用户点击"导出 PDF"
2
html2canvas 把报告 DOM 截图成画布
3
计算 A4 纸需要几页
4
jsPDF 把画布切片放入每一页
5
自动下载 PDF 文件

小测验

Q1：为什么加载页要同时运行动画和 API 调用，而不是先调 API 再放动画？

A：因为 API 调用很快不需要等
B：为了节省服务器资源
C：为了用动画掩盖等待时间，提升用户体验
D：因为代码写起来更简单

Q2：你想在报告页添加一个柱状图来展示薪资对比，你需要？

A：安装一个新的图表库
B：用 Recharts 的 BarChart 组件，项目已经有这个库了
C：用 CSS 手动画柱子
D：用截图插入静态图片

Q3：如果用户反馈"导出的 PDF 只有第一页有内容"，最可能的原因是？

A：浏览器不支持 PDF
B：html2canvas 截图失败
C：多页分割逻辑有问题，没有正确循环添加后续页面
D：报告内容太少不够一页
