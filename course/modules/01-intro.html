模块 1

这个应用做了什么？

从零认识「AI 职业定位报告」——它的功能、用户体验和技术工具

想象你走进社保局，想了解自己的职业定位。一位 AI 顾问接待了你——它问你几个问题，然后生成一份专业的职业分析报告。这就是这个应用做的事。

四大核心功能

📝

智能表单

收集你的基本信息——年龄、学历、工作经历等，就像体检时的「登记表」。

🤖

AI 访谈

AI 会像真人顾问一样追问你的细节，深入了解你的职业情况。

⏳

等待动画

AI 在后台分析时，页面会显示优美的加载动画，让你知道它正在「思考」。

📊

专业报告

最终输出一份带图表的职业分析报告，包括雷达图、饼图和具体建议。

💡 类比：就像体检

登记信息 → 医生问诊 → 等待化验 → 拿到报告。这个应用的流程一模一样，只不过「医生」换成了 AI。

用户旅程 — 从点击到报告

打开应用后，你会依次经历以下四个步骤。每一步都对应一个独立的页面。

1

填写表单

输入你的姓名、年龄、学历、工作年限等基本信息。表单会自动校验，确保信息完整。

→
2

AI 访谈

AI 根据你的信息提出 3-5 个针对性问题。你用文字回答，就像和真人聊天一样。

→
3

加载等待

AI 在后台综合分析你的所有数据。页面显示动画和进度提示，大约需要 30-60 秒。

→
4

查看报告

一份完整的职业定位报告呈现在你面前——包含评分、图表和个性化建议。

整个过程大约 5-10 分钟。数据存在浏览器的 sessionStorage 中，关闭页面后不会保留。

技术栈一览 — 搭建这个应用用了什么工具？

这个应用由 6 个核心工具搭建而成。现在不需要全部理解，后面的模块会逐一拆解。

⚡

Next.js

框架 — 应用的骨架。它决定了页面怎么组织、怎么跳转。

🔒

TypeScript

语言 — 更安全的 JavaScript。像给代码加了「拼写检查」。

🎨

Tailwind CSS

样式 — 让页面变好看。用预设的类名快速美化界面。

🧠

MiniMax API

AI 大脑 — 生成访谈问题和职业报告的核心引擎。

📈

Recharts

图表库 — 画雷达图和饼图，让报告数据一目了然。

✨

Framer Motion

动画库 — 让页面动起来，提供流畅的过渡效果。

代码翻译 — 读懂第一段代码

下面是这个应用的「根布局」代码——整个应用的最外层壳子。我们把每一行翻译成大白话。

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="zh-CN">
      <body className={`${geistSans.variable} antialiased`}>
        {children}
      </body>
    </html>
  );
}
第 1 行 导出一个叫 RootLayout 的函数 — 它是整个应用的「外壳」
第 2-4 行 它接收一个叫 children 的参数 — 就是要显示在里面的内容
第 5-6 行 返回 HTML 结构，设置语言为中文
第 7 行 给页面设置字体和抗锯齿效果
第 8 行 把子内容放进去 — 不同的页面会替换这里
